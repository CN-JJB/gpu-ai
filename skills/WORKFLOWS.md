# Skill Workflows

## A. 课程内容生产
```
teach
  → research
  → source/research note
  → lesson design
  → scaffold exercise/lab if useful
  → lesson
  → experiment/evidence
  → learning record
```

## B. 垃圾佬互联网考古
```
research
  → official docs/source code
  → issues/PR/forks/patches
  → community evidence
  → reproduce / diagnosing-bugs
  → Experiment Card
  → intelligence ingestion
```

## C. 工具/情报站功能
```
grill-with-docs (only if requirements still branch)
  → prototype (if a design question needs proof)
  → to-spec
  → to-tickets
  → codebase-design
  → implement
  → tdd / diagnosing-bugs
  → code-review
```

## D. 长任务
```
MISSION + COURSE-MAP + CURRENT
  → wayfinder
  → execute a bounded slice
  → update artifacts
  → handoff when context changes
```

## E. 学生卡住
```
read records/evidence
  → identify misconception
  → wait-what
  → new explanation or tiny experiment
  → retrieval/transfer check
  → update mastery
```
