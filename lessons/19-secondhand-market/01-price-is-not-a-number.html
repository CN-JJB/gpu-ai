Slice 19 — 中国二手 GPU：先学会“价格不是一个数字”

你打开闲鱼搜“3090”，第一屏能看到很多数字。真正的问题是：这些数字到底是不是同一种东西？

1. 一个最危险的例子

商品标题可能写：

RTX3050 / 3060 / 3070 / 3080Ti / 3090
¥1598

如果搜索页把最低选项显示为 ¥1598，你不能记：

3090 = 1598

这类链接可能把多个 SKU、配件、坏卡、定金放进一个商品。

规则：没有 exact option price，就不进入 exact-SKU 行情样本。

2. 二手市场至少有六种“价格”

状态意思
ASK卖家当前挂牌
SOLD-CONFIRMED平台明确显示成交
DELISTED-ASSUMED下架，被第三方推测成交
MERCHANT-QUOTE商家报价
BUYBACK回收价
UNKNOWN状态不明

它们不能直接混在一起算“均价”。

3. 同一个 GPU 名字也可能不是同一个产品

例如：

A770 8G
A770 16G

本地 LLM 对显存非常敏感，所以必须分开。

再比如：

2080 Ti 11G stock
2080 Ti 22G VRAM mod

后者已经是一个 custom hardware cohort。

4. “非矿”不是检测结果

卖家说：

  • 个人自用；
  • 女生自用；
  • 非矿；
  • 网吧拆机；
  • 服务器退役；
  • 无修。

全部先存成：

seller_claim

不要自动转成：

low risk

5. 证据强度应该单独记录

等级含义
C0无条件证据
C1卖家口述
C2有当前功能截图/视频
C3有身份、持续负载、显存/温度等完整测试
C4第三方或买家本人独立验证

6. 验货服务也不是万能 GPU 测试

平台第三方验货可以提高交易保障，但查验有明确服务范围和标准。

对 AI GPU，你仍然需要自己关心：

  • 显存容量是否正确；
  • 显存错误；
  • 持续 compute 稳定性；
  • 热点/显存温度；
  • 驱动重置；
  • BIOS；
  • 维修/魔改。

7. 为什么不能迷信“最低价”

正常样本里你更应该看：

n
median
Q1-Q3
confirmed sold sample
condition cohort

而不是：

min(listing)

最低的那条最可能恰好是：

  • 坏卡；
  • 配件；
  • 诈骗引流；
  • 修过；
  • 定金；
  • 错误型号。

8. 二手显卡不只有“矿卡风险”

本地 LLM 特别容易遇到：

  • 退役计算卡；
  • 涡轮/被动散热卡；
  • 显存魔改；
  • 无输出卡；
  • EPS 特殊供电；
  • 板修；
  • OEM 怪板；
  • 工程样品。

每一种都会改变：

平台成本
+ 测试成本
+ 故障概率
+ resale

9. 真正有用的是“我的最高买价”

你不应该问：

3090 值多少钱？

应该问：

对我的 32B Q4 + 16k context
这张 exact 3090
在当前软件和风险条件下
最高值得我付多少钱？

简化：

max buy price
= workload value
- platform extras
- repair reserve
- software burden
- condition/risk discount

10. 最终市场工作流

抓 listing
→ exact SKU
→ condition cohort
→ price state
→ duplicate/outlier cleanup
→ median/Q1-Q3
→ evidence grade
→ candidate dossier
→ BUY IF PRICE ≤ X

这才是“垃圾佬”真正可复用的市场能力。

学生闭环 — 二手市场价格证据

硬件门槛：L0 主路径；真实硬件/市场只是增强。

成本：0 元教学路径。

风险：safe；涉及真实二手交易时课程只提供调查/验收方法，不替你自动购买。

能力目标

  • 区分挂牌价、sold-marked price、确认成交价、二手报道/商家报价
  • 把地区、日期、成色、型号/显存、平台、样本规则写进价格证据
  • 拒绝用一个搜索结果或多 SKU 诱饵价代表市场

小实验 / 反馈

做 Experiment 33：secondhand market normalization；需要真实市场时做 Experiment 34：real market snapshot。

Retrieval Practice

  1. 为什么同一型号的最低展示价通常不是可用的 fair-value 证据？
  2. MEDIAN_ASK 与 confirmed transaction price 证明的事情相同吗？
  3. 跨人民币/美元市场比较时除了汇率还要处理哪些口径？
  4. 为什么动态价格不应该写死进稳定 Lesson？

完成证据

做一份 10 条样本的规范化 market table，明确 inclusion/exclusion、来源等级、观察日期和你不能声称的结论。

如何选择 / 迁移

以后调查 CPU、内存、整机或别的二手硬件，也沿用“同品类、同口径、同时间窗、证据等级”原则。
