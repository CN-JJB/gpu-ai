Thermal / Cooling — 为什么冷机 55 tok/s，十分钟后只剩 43？

1. 短跑和长跑不是一个硬件状态

workload starts
→ cooler still cool
→ clocks boost
→ heat accumulates
→ equilibrium
30 秒冷机跑分不能自动代表 30 分钟 sustained TG。

2. Temperature 不是唯一答案

温度由很多东西共同决定：

board power
ambient
heatsink
fan
case airflow
neighbor GPU
dust
form factor

3. 不要背一个万能 80°C

不同 GPU 有：

edge/core
hotspot/junction
memory temperature
different target/max

所以：

80°C = throttle

不是通用规则。

4. Clock 掉了也不一定是散热

NVIDIA 当前 clock-event reason 里就区分：

power cap
thermal slowdown
power brake
other limits

所以：

clock ↓

只能先说“发生了降频/状态变化”。

5. Synthetic thermal drift

time:   0 → 240s
temp:  55 → 86°C
clock:1900 →1450 MHz
TG:    55 → 42 tok/s

TG：

42 / 55
≈ 0.764

也就是约：

-23.6%

温升 + clock 下降 + TG 下降，thermal/power management 变得很可疑。

6. 但还不能直接判 exact cause

最好再看：

thermal event reason?
power cap?
power brake?
hotspot/memory temp?

7. Hot-but-stable case

temp 80 → 84°C
clock 1800 → 1790
TG 50 → 49.8

性能基本没掉。

所以：

温度高
!=
正在 throttle

8. Ambient 很重要

20°C room
vs
32°C room

同一张二手卡都可能完全不同。

买卡/换散热器对比要记 ambient。

9. Open bench 也会骗人

桌面裸奔：

fresh air everywhere

塞进机箱双卡：

GPU0 exhaust
→ GPU1 intake
→ recirculation

垃圾佬多卡尤其明显。

10. Fan / noise 是另一个目标

最低温度不一定是最好系统。

more fan
→ lower temp
→ more noise

真实目标可能是：

sustained tok/s
subject to
temperature + noise

11. llama-bench 为什么适合看 sustained drift？

当前 pinned 版本：

-r repetitions
-o jsonl
samples_ts[]
samples_ns[]

同一次模型加载里有每次 repetition 的 TG。

所以可以比较：

first quartile
vs
last quartile

12. Warmup 也要写进 manifest

default warmup
vs
--no-warmup

会影响前几个样本。

13. 实验默认不调功耗墙

先只读测：

TG
temperature
clock
power
event reasons

不默认做：

overclock
undervolt
power-limit change
fan curve change

14. 你最终要回答

这张卡：
峰值有多快？
热起来以后多快？
功率多少？
温度多少？
有没有 limiter evidence？
噪音/机箱是否可接受？

学生闭环 — Thermal / Cooling / Sustained Performance

硬件门槛：L0 模型/设计主路径；真机实验按页面对应 L1–L3。

成本：0 元教学主路径；不要求购买、拆修或高风险改造。

风险：默认 safe；涉及 PSU/硬件时只做只读调查与厂商手册约束下的正常安装，不做带电拆装。

能力目标

  • 把“GPU 很强”升级成整机层的容量、稳定、供电、散热和长期运行判断。
  • 把 PASS / FAIL / UNKNOWN 与具体 Evidence 对齐。
  • 知道什么情况下应该 BLOCKED 或 REVISE，而不是为了完成课程强行 ACCEPT。

小实验 / 反馈

做 Experiment 84：thermal sustained model；有 GPU 时做 Experiment 85：real sustained thermal。

Retrieval Practice

  1. 为什么 30 秒 benchmark 很快不能证明 30 分钟后仍然快？
  2. 温度高与 thermal throttling 是同一句话吗？
  3. 功率限制、温度限制、供电限制都会让 clocks 掉，你如何区分？
  4. 清灰/风道/降压优化为什么必须看 sustained TG 与稳定性，而不是只看温度数字？

完成证据

做一条 thermal-soak 时间线：温度、功率、clock、TG/PP、错误/重试，至少比较 warm-up 与 steady window；写出是否存在 drift 及可能原因。

如何选择 / 迁移

换 GPU、模型或平台后，从 hard gates 重新算，不继承旧机器的 PASS；任何新未知都回到 evidence collection，而不是靠经验口头补齐。
