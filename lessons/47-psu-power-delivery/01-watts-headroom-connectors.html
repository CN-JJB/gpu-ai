PSU / Power Delivery — 1000W 电源为什么仍然可能带不了你的 GPU？

1. 先拆掉第一个误区

PSU = 1000W

不等于：

任意一根线都能给 GPU 1000W
总容量和具体供电路径是两个不同 gate。

2. 先做系统功率算术

GPU
+ CPU/platform
+ storage/fans
+ other devices
= estimated DC load

例如：

300 + 180 + 70 = 550W

850W PSU 的算术余量：

300W
≈35.3%

3. 但 35.3% 也不是“证明安全”

因为还有：

transient / power excursion
connector path
cable compatibility
PSU protection/rail design
thermal condition

4. 课程不教万能 20% 法则

余量是你的 policy 输入。

不同：

PSU
GPU
multi-GPU
upgrade plan
workload

都可能需要不同策略。

5. 最危险的垃圾佬误区之一：模组线能插就能用

PSU-side plug fits
!= pinout compatible

Seasonic/Corsair 官方都明确要求检查具体 PSU/线材兼容性。

不同品牌，甚至同品牌不同系列，都可能不兼容。

6. 所以 1000W 也能直接 REJECT

1000W capacity
600W estimated load
but wrong modular cable
→ REJECT / STOP

剩余 400W 没任何意义。

7. GPU 还有两条供电来源

PCIe slot
+
auxiliary GPU connector(s)

不要假设：

少插一根线
→ 主板插槽会自动补回来

8. 12V-2x6 是什么？

当前 PCI-SIG 资料里，12V-2x6 是 CEM 5.1 定义、替代 12VHPWR 的连接器方案。

但：

看到 16-pin
!= 可以随便按一个固定功率用

GPU、PSU、线材、sense/实现都要匹配。

9. Pigtail / daisy-chain 也没有一句万能答案

不要背：

一根双头永远可以
or
一根双头永远不可以

看 exact PSU + GPU manufacturer guidance。

10. 多 GPU 更容易把问题放大

GPU0 300W
GPU1 300W
platform 220W
= 820W

850W PSU 只剩：

30W
≈3.5%

在一个要求更多 headroom 的 policy 下，应当 REVIEW。

11. Board power 和电表也不同

nvidia-smi / vendor board power
!= wall power

墙上电表还包含：

CPU/RAM/主板/风扇/PSU loss

12. Real lab 最重要的是 cable map

PSU port
→ physical cable
→ branch
→ GPU connector

每根线写清楚型号/来源/兼容性证据。

13. 外观检查

关机、断开市电后，只检查外部可见部分：

是否完全插入
烧蚀/变色
熔化
线材损伤
异常弯折/拉力

看到烧蚀/电弧痕迹：

STOP USE

14. 默认课程绝对不做

拆 PSU 外壳
测裸露市电
短接/绕过保护
故意过载
自制高压测试

PSU 内部不是“垃圾佬低风险实验区”。

15. 最后决定

capacity gate
+
connector/cable gate
+
ordinary workload evidence
→ ACCEPT / REVIEW / REJECT
