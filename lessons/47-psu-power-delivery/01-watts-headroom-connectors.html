PSU / Power Delivery — 1000W 电源为什么仍然可能带不了你的 GPU？

Prerequisite Check

开始前，你应该知道 PSU 的总额定瓦数只是一个入口指标，还要同时检查 GPU/CPU/整机负载、瞬态余量、12V 供电能力、连接器类型、线材分配与厂商限制。

如果还不熟：先遵守两条安全边界：不要自行改造电源线材或混用不兼容的模块化 PSU 线；课程中的功率估算用于筛除明显不可行方案，最终连接方式以硬件厂商文档为准。

真实问题

你淘到一张高功耗二手 GPU，机箱里已经有“1000W 电源”，看起来容量很大；但如果连接器不匹配、单路/线材分配不合适、瞬态余量太小或整机其他部件占用过多，系统仍可能在负载下掉电或不稳定。

真正的问题是：这套电源与线材能否在不改线、不冒险的前提下，为整机提供足够的持续与瞬态 headroom，并满足 GPU 厂商规定的连接方式？若证据不完整，结论应是 BLOCKED，而不是“先插上试试”。

1. 先拆掉第一个误区

PSU = 1000W

不等于：

任意一根线都能给 GPU 1000W
总容量和具体供电路径是两个不同 gate。

2. 先做系统功率算术

GPU
+ CPU/platform
+ storage/fans
+ other devices
= estimated DC load

例如：

300 + 180 + 70 = 550W

850W PSU 的算术余量：

300W
≈35.3%

3. 但 35.3% 也不是“证明安全”

因为还有：

transient / power excursion
connector path
cable compatibility
PSU protection/rail design
thermal condition

4. 课程不教万能 20% 法则

余量是你的 policy 输入。

不同：

PSU
GPU
multi-GPU
upgrade plan
workload

都可能需要不同策略。

5. 最危险的垃圾佬误区之一：模组线能插就能用

PSU-side plug fits
!= pinout compatible

Seasonic/Corsair 官方都明确要求检查具体 PSU/线材兼容性。

不同品牌，甚至同品牌不同系列，都可能不兼容。

6. 所以 1000W 也能直接 REJECT

1000W capacity
600W estimated load
but wrong modular cable
→ REJECT / STOP

剩余 400W 没任何意义。

7. GPU 还有两条供电来源

PCIe slot
+
auxiliary GPU connector(s)

不要假设：

少插一根线
→ 主板插槽会自动补回来

8. 12V-2x6 是什么？

当前 PCI-SIG 资料里，12V-2x6 是 CEM 5.1 定义、替代 12VHPWR 的连接器方案。

但：

看到 16-pin
!= 可以随便按一个固定功率用

GPU、PSU、线材、sense/实现都要匹配。

9. Pigtail / daisy-chain 也没有一句万能答案

不要背：

一根双头永远可以
or
一根双头永远不可以

看 exact PSU + GPU manufacturer guidance。

10. 多 GPU 更容易把问题放大

GPU0 300W
GPU1 300W
platform 220W
= 820W

850W PSU 只剩：

30W
≈3.5%

在一个要求更多 headroom 的 policy 下，应当 REVIEW。

11. Board power 和电表也不同

nvidia-smi / vendor board power
!= wall power

墙上电表还包含：

CPU/RAM/主板/风扇/PSU loss

12. Real lab 最重要的是 cable map

PSU port
→ physical cable
→ branch
→ GPU connector

每根线写清楚型号/来源/兼容性证据。

13. 外观检查

关机、断开市电后，只检查外部可见部分：

是否完全插入
烧蚀/变色
熔化
线材损伤
异常弯折/拉力

看到烧蚀/电弧痕迹：

STOP USE

14. 默认课程绝对不做

拆 PSU 外壳
测裸露市电
短接/绕过保护
故意过载
自制高压测试

PSU 内部不是“垃圾佬低风险实验区”。

capacity gate
+
connector/cable gate

→ ACCEPT / REVIEW / REJECT

完成证据

教材补全：供电验收有三道独立 Gate

Gate A: total capacity
Gate B: connector/cable compatibility
Gate C: sustained ordinary workload behavior

三道都通过，才有资格说“供电方案可接受”。任何一道硬失败，都不能被另外两道的好成绩抵消。

Worked Example：1200W 仍然 BLOCKED

estimated load = 700W
PSU rating = 1200W
headroom = large

BUT:
modular GPU cable provenance unknown

这时容量算术非常漂亮，但 cable pinout/兼容性属于安全关键 UNKNOWN，因此应该 BLOCKED，直到找到 exact PSU/cable 厂商证据。

不要用“插得进去”验证模组线

PSU 端模块化接口没有跨品牌统一 pinout 保证。课程只接受具体型号的厂商兼容表、原厂线材标识或等价可靠来源，不接受“接口一样”。

Transient 为什么重要？

平均功率低于额定值不代表所有瞬时功率变化都能被系统稳定处理。真正判断仍需要 exact GPU/PSU guidance 与正常 workload 下的稳定性证据，而不是故意制造危险过载。

Multi-GPU 还要检查物理路径

PSU port
→ cable
→ branch
→ connector
→ GPU

除了总瓦数，还要确认每张卡实际如何取电、线材是否共享、厂商是否允许该接法。

安全边界

出现熔化、烧蚀、异常发热/气味、可疑模组线来源时停止使用。课程不指导拆 PSU、测市电裸露节点、绕过保护或自制危险适配。

Troubleshooting：负载下重启或掉卡时，先做什么？

  1. 先停止高负载并断电检查：如果出现掉电、重启、烧焦气味、异常发热或连接器变色，不继续反复压测。
  2. 核对 exact PSU 与线材身份：确认模组线确实属于该 PSU 型号/系列，并按 PSU 与 GPU 厂商文档核对连接方式。不要用“插得进去”当兼容证据。
  3. 重新做整机预算：把 GPU、CPU、其他设备和安全余量放回同一张功率表；不要只比较 GPU board power 与 PSU 总瓦数。
  4. 检查连接器路径：记录 GPU 每个供电入口、使用的线材和 PSU 端口；不确定的适配器、分线或第三方线材直接记为 BLOCKED，等待可靠文档确认。
  5. 如果只有高瞬时负载触发：把 transient/headroom 作为假设，而不是马上通过改电压、改线或替换保护机制“修好”。
  6. 换已知良好的兼容组件做隔离时：仍要保持厂商规定的连接方式，并一次只改变一个变量，保存前后 Evidence。
安全停止条件：任何涉及未知线序、烧蚀、裸露导体、带电测量或保护电路绕过的情况，本课程路径直接停止并交给合格人员/厂商文档处理。

Decision Rule

容量足够只是必要条件，不是充分条件。安全关键 cable/connector provenance 不明确时，整机方案保持 BLOCKED。
