PSU / Power Delivery — 1000W 电源为什么仍然可能带不了你的 GPU？

1. 先拆掉第一个误区

PSU = 1000W

不等于：

任意一根线都能给 GPU 1000W
总容量和具体供电路径是两个不同 gate。

2. 先做系统功率算术

GPU
+ CPU/platform
+ storage/fans
+ other devices
= estimated DC load

例如：

300 + 180 + 70 = 550W

850W PSU 的算术余量：

300W
≈35.3%

3. 但 35.3% 也不是“证明安全”

因为还有：

transient / power excursion
connector path
cable compatibility
PSU protection/rail design
thermal condition

4. 课程不教万能 20% 法则

余量是你的 policy 输入。

不同：

PSU
GPU
multi-GPU
upgrade plan
workload

都可能需要不同策略。

5. 最危险的垃圾佬误区之一：模组线能插就能用

PSU-side plug fits
!= pinout compatible

Seasonic/Corsair 官方都明确要求检查具体 PSU/线材兼容性。

不同品牌，甚至同品牌不同系列，都可能不兼容。

6. 所以 1000W 也能直接 REJECT

1000W capacity
600W estimated load
but wrong modular cable
→ REJECT / STOP

剩余 400W 没任何意义。

7. GPU 还有两条供电来源

PCIe slot
+
auxiliary GPU connector(s)

不要假设：

少插一根线
→ 主板插槽会自动补回来

8. 12V-2x6 是什么？

当前 PCI-SIG 资料里，12V-2x6 是 CEM 5.1 定义、替代 12VHPWR 的连接器方案。

但：

看到 16-pin
!= 可以随便按一个固定功率用

GPU、PSU、线材、sense/实现都要匹配。

9. Pigtail / daisy-chain 也没有一句万能答案

不要背：

一根双头永远可以
or
一根双头永远不可以

看 exact PSU + GPU manufacturer guidance。

10. 多 GPU 更容易把问题放大

GPU0 300W
GPU1 300W
platform 220W
= 820W

850W PSU 只剩：

30W
≈3.5%

在一个要求更多 headroom 的 policy 下，应当 REVIEW。

11. Board power 和电表也不同

nvidia-smi / vendor board power
!= wall power

墙上电表还包含：

CPU/RAM/主板/风扇/PSU loss

12. Real lab 最重要的是 cable map

PSU port
→ physical cable
→ branch
→ GPU connector

每根线写清楚型号/来源/兼容性证据。

13. 外观检查

关机、断开市电后，只检查外部可见部分：

是否完全插入
烧蚀/变色
熔化
线材损伤
异常弯折/拉力

看到烧蚀/电弧痕迹：

STOP USE

14. 默认课程绝对不做

拆 PSU 外壳
测裸露市电
短接/绕过保护
故意过载
自制高压测试

PSU 内部不是“垃圾佬低风险实验区”。

15. 最后决定

capacity gate
+
connector/cable gate
+
ordinary workload evidence
→ ACCEPT / REVIEW / REJECT

学生闭环 — PSU / Power Delivery / Platform Integration

硬件门槛：L0 模型/设计主路径；真机实验按页面对应 L1–L3。

成本：0 元教学主路径；不要求购买、拆修或高风险改造。

风险：默认 safe；涉及 PSU/硬件时只做只读调查与厂商手册约束下的正常安装，不做带电拆装。

能力目标

  • 把“GPU 很强”升级成整机层的容量、稳定、供电、散热和长期运行判断。
  • 把 PASS / FAIL / UNKNOWN 与具体 Evidence 对齐。
  • 知道什么情况下应该 BLOCKED 或 REVISE，而不是为了完成课程强行 ACCEPT。

小实验 / 反馈

做 Experiment 88：PSU power-budget model；真实机器做 Experiment 89：real PSU/platform dossier。

Retrieval Practice

  1. GPU TGP 加 CPU TDP 为什么不是精确 PSU sizing？
  2. 额定瓦数足够时，为什么 connector/cable/rail/瞬态仍可能是问题？
  3. 一根分叉线给高功耗双 8-pin GPU 为什么不能只按“插得进去”判断？
  4. 电源 headroom 的意义是让你永远低负载，还是吸收峰值/老化/平台变化？

完成证据

做一份真实或假设整机 power dossier：GPU/CPU/其他负载、PSU 型号/额定、接头与线材路径、余量、已知限制、UNKNOWN；任何具体接线必须以该 PSU/GPU 厂商手册为准。

如何选择 / 迁移

换 GPU、模型或平台后，从 hard gates 重新算，不继承旧机器的 PASS；任何新未知都回到 evidence collection，而不是靠经验口头补齐。
