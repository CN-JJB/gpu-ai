Slice 20 — 二手 GPU 到手怎么验：不是“烤机通过”四个字

1. 先把“健康”拆开

身份对不对？
显存容量对不对？
显存数据完整吗？
计算稳定吗？
温度正常吗？
会降频吗？
驱动会 reset 吗？
我的 LLM workload 能稳定跑吗？

这些问题必须分别取证。

2. 付款前先让卖家证明“这就是这张卡”

要求：

  • 当前时间/订单提示的实拍；
  • 序列号标签；
  • GPU/VRAM 识别；
  • 当前负载视频；
  • 负载后的温度；
  • 维修/改显存/BIOS 情况。
“个人自用、非矿、无修”先全部当 seller claim，而不是检测结论。

3. 到货第一件事不是插电脑

先留：

包裹
→ 运单
→ 开箱
→ 序列号
→ PCB/接口/散热器外观

如果外观已经有烧蚀、严重腐蚀、破损电源口，就没有必要冒风险通电。

4. 第一个上机测试：Identity

NVIDIA

nvidia-smi -L
nvidia-smi -q

AMD

amd-smi list
amd-smi static
rocminfo

Intel

sycl-ls
llama-bench --list-devices

确认：

  • 型号；
  • 显存；
  • device ID；
  • BIOS/firmware（需要时）。

5. “跑游戏没花屏”不能证明显存完整

显存问题是独立层。

NVIDIA 支持的产品可以使用官方 DCGM memory diagnostics；跨生态还可以把 memtest_vulkan 作为额外证据。

核心逻辑：

allocate
→ write patterns
→ read back
→ compare
→ report errors

如果一张“正常工作卡”能稳定复现显存错误，已经是很强的拒收信号。

6. 但显存测试通过，也没结束

接下来用自己的 workload：

same model
→ llama-bench PP
→ llama-bench TG
→ repeat
→ log

这能同时碰到：

  • 模型大 allocation；
  • 矩阵运算；
  • backend kernel；
  • 持续显存带宽；
  • 温度/功耗。

7. 为什么 FurMark 不是终局？

FurMark 可以是一个负载工具，但它回答不了所有问题。

测试主要回答
graphics stress图形/高功耗负载能否持续
memory test显存数据完整性
LLM PP矩阵/prefill 路径
LLM TG显存带宽/解码稳定
error counters硬件/driver 报错

8. 温度也不是只看 GPU Core

能读到的话记录：

  • core；
  • hotspot；
  • memory junction；
  • fan；
  • clock；
  • power；
  • throttle reason。

3090 这种 GDDR6X 卡尤其不能只盯 core 温度。

9. 计算卡要多验一层

P40/P100/V100/A 系列等：

正常计算
+
ECC/RAS
+
散热方案
+
供电/机箱兼容
+
无显示输出工作流

一张本身没坏的 P40，如果你的机箱根本无法正确给被动散热器送风，对你仍然不是“可用卡”。

10. 魔改卡/板修卡不是自动拒绝

但必须进入更高风险 cohort。

例如 2080 Ti 22G：

  • 能识别 22G；
  • 接近满显存 allocation；
  • 显存测试；
  • 目标 LLM；
  • 驱动重启测试；
  • 卖家/改卡者 provenance。

价格必须补偿风险。

11. 正确测试顺序

visual
→ identity
→ baseline errors
→ short memory
→ short LLM
→ sustained LLM
→ optional deeper diagnostics
→ final log review

失败得越早，就越不要继续无意义地烤。

12. 最后输出

  • ACCEPT
  • ACCEPT WITH DISCLOSED DEFECT
  • DISPUTE / RETURN

真正强的二手买家不是“敢赌”，而是：

每个关键结论
都有证据

学生闭环 — 二手 GPU 付款前与到货验收

硬件门槛：L0 主路径；真实硬件/市场只是增强。

成本：0 元教学路径。

风险：safe；涉及真实二手交易时课程只提供调查/验收方法，不替你自动购买。

能力目标

  • 把卖家 claim、外观证据、设备身份、显存/PCIe/错误、持续负载分层验证
  • 知道什么问题适合付款前问，什么必须到货后自己测
  • 用 ACCEPT / REVIEW / REJECT 而不是“能亮机就没问题”

小实验 / 反馈

做 Experiment 35：seller evidence quality；有真实卡时做 Experiment 36：real used-GPU acceptance。

Retrieval Practice

  1. GPU-Z/nvidia-smi 能识别型号，为什么仍不能证明显存完全健康？
  2. 短跑 benchmark PASS 为什么不能替代 sustained soak？
  3. 卖家说“无修无矿”和你能验证的事实之间差了什么？
  4. 发现 PCIe link 异常时为什么先排平台/插槽/负载状态，而不是马上判坏卡？

完成证据

写一份二手卡验收 SOP：付款前材料、到货身份、显存/错误、PCIe、温度功耗、持续 LLM workload、退货阈值，并为每项说明证据强度。

如何选择 / 迁移

不同厂商命令会换，但验收逻辑不变：identity → integrity → link → sustained workload → decision boundary。
