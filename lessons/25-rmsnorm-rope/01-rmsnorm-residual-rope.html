LLM 架构 2 — RMSNorm、Residual、RoPE：尺度、信息和位置

这三个组件参数都不算模型里的“大块头”，但少一个都可能让整个模型函数变掉。

1. RMSNorm：它不是把均值变成 0

对 hidden vector：

x = [x₁, x₂, ... x_d]

先算：

RMS(x) = sqrt(mean(x²) + eps)

然后：

y = g ⊙ x / RMS(x)

g 是训练出来的 scale。

和 LayerNorm 最直观的区别：RMSNorm 不显式减掉 mean。

2. 为什么放大输入后，RMSNorm 输出不跟着放大？

忽略 epsilon：

RMS(3x) = 3 RMS(x)

所以：

3x / RMS(3x)
=
x / RMS(x)

这就是 re-scaling invariance 的直觉。

3. 参数很少，不等于免费

RMSNorm 的 learned weight 只有大约：

d

而一个大 linear 可能是：

d × d

但 inference 仍要做：

read
→ square
→ reduce
→ rsqrt
→ multiply

尤其 decode 的大矩阵利用率较低时，这类小 kernel/fusion 也会变得更显眼。

4. Residual：不要让每个 sublayer 都“从零重写” hidden state

h = x + Attention(RMSNorm(x))
y = h + MLP(RMSNorm(h))

心智模型：

已有表示
+
新学到的 update
=
下一层表示

Residual 本身没有几十亿参数，但它是 block 数据依赖的骨架。

5. 位置问题来了

Attention 如果不知道顺序，下面两句的 token 集合很像：

dog bites man
man bites dog

但意思完全不同。

RoPE 不直接给 embedding 加一个 position vector，而是对 Q 和 K 的维度对做旋转。

6. 先看二维旋转

[x₀']   [ cosφ  -sinφ ] [x₀]
[x₁'] = [ sinφ   cosφ ] [x₁]

旋转有个很重要的性质：

||x'|| = ||x||

它改变方向，不改变这个二维向量的长度。

7. RoPE：不同 position 转不同角度

第 i 对维度有自己的频率：

φᵢ(p) = p × ωᵢ

position 越不同，旋转关系越不同。

8. 为什么说它把“相对距离”放进 attention？

q'_p = R(p)q
k'_s = R(s)k

点积：

(q'_p)ᵀ k'_s
≈
qᵀ R(s-p) k

关键在：

s - p

所以如果把两个位置一起 +10，它们的相对 offset 没变，基础 RoPE 的这部分点积关系也不变。

9. 这和 KV Cache 有什么关系？

Prompt prefill 时，每个 historical K 对应自己的 position。

token at position 0 → K₀
token at position 1 → K₁
...
token at position S-1 → Kₛ₋₁

Decode 的新 Q 在当前 position S。

Q_S
→ compare with
K_0 ... K_{S-1}
所以 KV cache 不只是“token 内容缓存”。Position/RoPE state 也是它逻辑身份的一部分。

10. 为什么 Prefix Cache 不能只看字符串一样？

真正需要一致的是：

tokenization
+ model
+ context state
+ position
+ RoPE configuration

同样文本如果处在不同需要重映射的位置状态，不能无脑把 K/V 当完全同一个 cache object。

11. RoPE 不会让 KV 变宽

旋转前：

K [B,Hkv,S,Dh]

旋转后逻辑 shape 仍是：

K [B,Hkv,S,Dh]

所以 KV 主公式仍然是：

2 × layers × Hkv × Dh × bytes × tokens

12. rope_theta 与 rope_scaling

真实 model config 经常有：

rope_theta
rope_scaling

它们改变频率/位置映射。

最危险的误区：

我显存够 128k KV
→ 模型就一定能高质量跑 128k

错误。

要分开：

memory capacity
vs
position extrapolation quality

13. 三个组件各自解决什么？

组件主要作用大参数矩阵？
RMSNorm控制 hidden scale否
Residual保留/累加表示否
RoPE把 position 放进 Q/K geometry否

但任何一个错了，都不是“性能差一点”，而可能是模型函数错了。
