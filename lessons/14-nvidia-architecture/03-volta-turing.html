NVIDIA 架构 3 — Volta → Turing：AI 硬件正式进入 SM

1. Volta 的历史转折：Tensor Core

在 Volta 之前，低精度 AI 主要利用普通 CUDA execution datapath / packed primitives。

Volta 把 matrix multiply-accumulate 变成专门硬件：

warp
→ matrix fragments
→ Tensor Core MMA
→ accumulator

这不是“CUDA core 更快”，而是增加新的 execution unit 类型。

2. 为什么 matrix unit 有意义？

神经网络最重的工作有大量规则 GEMM：

[M×K] × [K×N]

如果硬件直接针对 tile MMA 设计，就能：

  • 提高每条 instruction 表达的 MAC 数；
  • 复用 operands；
  • 减少 scheduler/control overhead；
  • 高效使用低精度。

3. 但 Volta 更深的变化是 Independent Thread Scheduling

旧 CUDA 程序常写出这种隐含假设：

"反正一个 warp 是 lockstep，
所以 lane 之间不用显式 sync"

Volta 以后这个假设不安全。

新的规则

  • warp intrinsics 使用带 mask 的 *_sync 版本；
  • 需要 memory exchange 时显式 __syncwarp()；
  • 不要把 warp-synchronous behavior 当隐式 barrier。
第四次重要抽象：warp 仍是 scheduler 的核心单位，但线程同步语义不等于“永远严格锁步”。

4. Volta 的 unified on-chip data cache

GV100 将 L1、texture、shared backing 组织成大的 unified data-cache structure，并允许 shared-memory carveout。

这让 on-chip memory tuning 更灵活，也降低某些 direct-global/load spill 的成本。

5. Turing：把 Volta 的现代 compute 思想带进 RTX

Turing 不是“Volta + RT Core”这么简单。

Dedicated FP32 + INT32

FP pipe: math
INT pipe: address/pointer/integer math
→ can make progress concurrently

现代 kernel 中 address generation 很多。如果整数地址计算总阻塞 FP pipeline，会浪费吞吐。

Independent Thread Scheduling

Turing 继承 Volta 的现代 warp synchronization model，这使新 CUDA semantics 进入 mainstream RTX。

Second-generation Tensor Core / inference types

Turing MMA 支持扩展到：

  • FP16；
  • INT8；
  • INT4；
  • 更低位 binary path。

这使 Turing 成为 inference-oriented AI hardware 的重要节点。

6. RT Core 为什么只轻讲？

RT Core 是 Turing 的标志，但本课程不做完整图形学。

我们只抽取一个长期趋势：

GPU
= programmable SM
+ workload-specific accelerators

后面 Tensor Core、TMA、AI control hardware 都属于这类“专用单元越来越多”的方向。

7. Turing unified L1/shared

Turing 的 compute workload 可在统一 96 KB L1/shared 资源中选择 carveout。

这延续 Volta 的统一 on-chip memory 方向。

8. 为什么 Turing 对本地 AI 特别重要？

从架构层面，它同时具备：

  • modern CUDA synchronization；
  • Tensor Core inference formats；
  • 独立 FP/INT datapath；
  • 较现代 cache/shared hierarchy。

从 2026 软件层面，它又刚好处在“当前 CUDA 支持线”的老端；这个结论会放在 dynamic intelligence，而不是历史 Lesson。

学生闭环 — Volta / Turing

硬件门槛：L0；真机增强 L1/L2（任意 NVIDIA GPU 均可做 capability inventory）。

成本：0 元主路径；不要求为历史架构买卡。

风险：safe；只读资料、设备信息与 benchmark。

替代路径：没有对应年代 GPU 也能完成 Experiment 23；有 NVIDIA 卡才做 Experiment 24。

能力目标

  • 从“上一代瓶颈 → 本代机制 → 今天 LLM 的影响”解释本页，而不是背型号。
  • 把 architecture family 与具体 SKU 的显存、带宽、互联、precision、功耗和软件生命周期分开。
  • 识别哪些是稳定架构事实，哪些必须在当前 driver/runtime 上重新验证。

小实验 / 反馈

做 Experiment 23：NVIDIA generation feature traps。如果手里有 NVIDIA 卡，再做 Experiment 24：real NVIDIA capability inventory。
