Vendor Capstone 2 — AMD ROCm/HIP

1. AMD 第一身份不是“RX 7000”，是 exact gfx target

amd-smi list
rocminfo
hipconfig --full

记录 exact GPU + gfx* + ROCm/HIP version。

2. 当前 llama.cpp HIP 构建

HIPCXX="$(hipconfig -l)/clang" HIP_PATH="$(hipconfig -R)" \
cmake -S . -B build \
  -DGGML_HIP=ON \
  -DGPU_TARGETS=<exact-gfx-target> \
  -DCMAKE_BUILD_TYPE=Release

cmake --build build --config Release -j

upstream 当前说明 GPU_TARGETS 可省略；课程显式写它是为了让 Evidence 更清楚。

3. 不要把 workaround 悄悄当官方支持

如果必须使用 gfx override、社区 patch、特殊 build：

support_state = community-enabled

这会进入 TCO/维护成本。

4. 第一轮优化仍由证据选

  • PP 弱 → FA/backend；
  • TG 接近 bandwidth roof → quant/memory traffic；
  • 长 context 内存紧 → KV/context；
  • 设备根本不在当前官方支持矩阵 → 先解决 support gate。
