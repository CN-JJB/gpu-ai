Vendor Capstone 1 — NVIDIA CUDA

目标不是“CUDA 最快”，而是把 NVIDIA 的成熟软件栈变成一份可审计 baseline。

1. 先证明是哪张卡

nvidia-smi -L
nvidia-smi --query-gpu=name,compute_cap,driver_version,memory.total,pci.bus_id --format=csv

旧卡尤其要同时检查当前 CUDA/driver 生命周期。能被驱动看到，不代表最新工具链仍支持。

2. 当前 llama.cpp CUDA 构建

cmake -B build -DGGML_CUDA=ON
cmake --build build --config Release

然后：

./build/bin/llama-bench --version
./build/bin/llama-bench --list-devices
backend 证据来自实际 build/device log，不来自“我装了 CUDA”。

3. Baseline

进入 Experiment 40，固定 model SHA、PP/TG、offload、KV、FA、threads。

4. 看到什么再优化什么

  • TG 接近 bandwidth roof → 优先研究 weight bytes / quant / memory behavior。
  • PP 弱、TG 正常 → 看 FA / matrix kernel。
  • 显存边缘化 → 看 KV/context/quant。
  • 双卡缩放差 → 回 Slice 11 看 P2P/topology/split。

5. CUDA 成熟也不能跳过实验

同一 NVIDIA 卡在不同 llama.cpp commit、quant、FA、context 下仍可能完全不同。
