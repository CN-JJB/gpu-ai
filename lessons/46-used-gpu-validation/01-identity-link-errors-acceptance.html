二手显卡验收 — “系统显示型号正常”为什么远远不够？

1. 先把卖家描述变成可检查的字段

型号
VRAM
板卡/子厂
接口
工作状态

然后逐个找独立证据。

外壳贴纸和一个 GPU 名称字符串都只是证据之一。

2. 身份至少交叉看

PCI vendor/device/subsystem
BDF / UUID
runtime product name
VRAM
VBIOS
board info

字段互相一致，可信度才提高。

3. 对垃圾佬最关键的是 VRAM

你买卡就是为了 24 GiB：

卖家：24 GiB
驱动/runtime：约 12 GiB

这不是小误差，是购买关键 claim 冲突。

4. PCIe Gen1/x1 先别急着退货

你可能在 idle 时看到低 current state。

current link
!= max capability

而且主板、CPU lanes、riser、bifurcation 都可能限制链路。

5. 真正要记两组

max/capable Gen + width
current negotiated Gen + width

如果要判断负载状态，再在普通 workload 下观察。

6. ECC N/A 不是“0 错误”

很多消费卡没有你期待的 ECC/RAS 字段。

NOT_SUPPORTED
!=
0 errors

写 N/A，继续用其他证据。

7. 什么错误更值得警惕？

uncorrectable ECC/RAS
repeated XID/runtime error
PCIe recovery/replay异常增长
bad pages
普通 inference 反复 crash

但每个字段是否支持，要看具体卡和驱动。

8. 一次 30 秒通过意味着什么？

这个 30 秒窗口没看到错误

只意味着这个。

不意味着：

永久可靠
所有显存地址都好
所有 DP/HDMI 都好

9. 最有价值的测试是你真的要跑的 workload

直接复用课程 sustained TG：

固定 model SHA
固定 runtime
重复 TG
记录 temp / clock / errors

因为你买卡就是为了 Local LLM。

10. 温度高也别单独判死刑

温度
+
clock
+
TG drift
+
limiter/event

一起看。

11. 显示坏和计算坏不是一回事

如果你只做 headless inference：

HDMI 坏
但 compute 稳定

可能是你愿意接受的折价缺陷。

但必须明确记录，不能当“全好”。

12. 默认课程不做什么？

刷 VBIOS
超频/降压
改 power limit
错误注入
破坏性 VRAM stress

先把只读证据和普通工作负载做扎实。

13. 最后的决定只有三类

ACCEPT
REVIEW
REJECT

不要写：

“看起来应该没问题”

14. 一个好验收包

seller claim
+ identity
+ VRAM
+ PCIe
+ error state
+ sustained TG
+ thermal
+ physical/display
→ decision
