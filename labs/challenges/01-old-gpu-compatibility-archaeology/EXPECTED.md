# Expected — Challenge 01

没有“正确旧卡”。

合格结果必须：
- exact SKU，而不是系列名；
- 分开 hardware / driver / runtime / backend；
- 至少一个 current upstream compatibility source；
- 至少一个明确 UNKNOWN 或说明为何无关键 UNKNOWN；
- 把散热/供电/平台成本计入；
- 不使用 synthetic benchmark 作为真实性能；
- 真机路径先 correctness 再 performance。

优秀结果能解释：
“这张卡为什么理论上有能力，但今天仍可能不值得折腾。”
