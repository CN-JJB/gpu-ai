# Expected — Experiment 87

There is no universal real-card result.

A valid packet must:
- write the seller/purchase claim before interpreting results;
- capture independent hardware/runtime identity;
- verify purchase-critical VRAM;
- distinguish PCIe capability from current state;
- keep unsupported ECC/RAS as N/A/UNKNOWN;
- run the intended ordinary sustained Local-LLM workload;
- report thermal/clock/performance drift;
- test display ports separately if required;
- end in ACCEPT / REVIEW / REJECT with explicit evidence.

The default lab must not flash firmware or modify clocks/power/fans.

An error-free test window is not a lifetime-reliability guarantee.
