# Seller Evidence Request Template

可直接按商品修改，不需要把它变成审讯。

你好，我主要拿这张卡跑本地 AI/LLM，想在下单前确认几个硬件状态，麻烦方便时帮我补一下：

1. **实物身份**
   - 正反面实拍
   - 序列号/标签
   - 显卡具体型号和显存容量

2. **维修/改动**
   - 是否修过 PCB/核心/显存
   - 是否换过显存颗粒
   - 是否改过显存容量
   - 是否刷过非原厂 BIOS
   - 是否换过散热器/风扇/导热垫

3. **当前运行证据**
   最好录一个连续视频，包含：
   - 当前日期或我这条消息/订单备注
   - GPU-Z / nvidia-smi / 对应厂商识别页面
   - 显存容量
   - 跑一段持续负载
   - 负载后的温度/频率
   - 全程无花屏/掉驱动

4. **如果是计算卡**
   - ECC/RAS 有没有报错
   - 原本是什么机器拆下
   - 散热方式
   - 电源接口/线材是否包含

5. **交易约定**
   如果到手出现：
   - 型号/显存不符
   - 未披露维修/改显存
   - 可复现显存错误
   - 反复掉驱动/花屏

   是否支持按平台流程退货/处理？

谢谢。
