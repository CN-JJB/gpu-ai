# Expected — Experiment 59

No universal quality result.

A valid A/B requires:
- same tokenizer;
- same corpus bytes;
- same evaluation method;
- exact artifacts;
- one intended variable where possible.

A lower candidate PPL is better predictive fit on that fixed evaluation.
A higher candidate PPL indicates degradation on that evaluation.

Neither result alone proves:
- chat helpfulness;
- coding quality;
- long-context quality;
- universal model superiority.

The final decision must include target-task evidence.
